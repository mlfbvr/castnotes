# CastNotes

## Angler App

CastNotes in an app for anglers to record their catches:

- What species
- Where and when it was caught
- How it was caught (technique, bait, lure, etc)
- Size (length and weight)
- Picture

## Features

- User authentication and profiles
- Catch logging with detailed information
- Fishing Sessions
- GPS coordinates for catch locations
- Public and private catch logs
- Photo uploads
- Location tagging with maps
- Social sharing and community features (coming later)
- Analytics and statistics on catches (coming later)
