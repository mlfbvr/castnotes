# Gemini Project Context: CastNotes

This file provides context for the "CastNotes" project, a planned web application for anglers to log their catches.

## Directory Overview

This directory contains the initial planning and feature definition documents for the CastNotes application. It is currently a non-code project focused on establishing the project's requirements and vision. The plan is to build the application using Django and PostgreSQL for the backend, with a React frontend.

## Key Files

*   **`NOVICE_FEATURES.md`**: This document outlines the core features for the initial version of the application, targeted at novice anglers. It describes a simple, mobile-first web app for logging basic catch details like species, photo, location, and date. The codename for this version is "CastNotes".

*   **`EXPERIENCED_FEATURES.md`**: This document details a more advanced set of features for a version of the application aimed at experienced anglers. It focuses on data analysis, detailed logging (including weather, water conditions, and specific tackle), a statistics dashboard, and pattern analysis. The codename for this version is "Angler's Almanac".

## Usage

The files in this directory serve as the primary source of truth for the project's requirements. Any future development work should refer to these documents to ensure it aligns with the defined features and target user personas.
- The **Novice** feature set should be considered the Minimum Viable Product (MVP).
- The **Experienced** feature set represents a future, more advanced version of the application.
